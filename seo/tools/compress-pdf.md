## Why PDFs get heavy in the first place

A typed document is tiny, often under 200KB. A scanned one is heavy because every page is a photograph, frequently saved at 300 DPI or more. Ten scanned pages at 1.5MB each is a 15MB file, and 95% of that weight is image data rather than text.

That is also why compression helps so much: reducing the images to a sensible DPI and quality removes most of the bytes without touching the text layer.

## Targets for Indian government and bank portals

Most portals ask for under 2MB, many ask for 500KB, and a few stubborn ones cap at 100–200KB. Set the target instead of pushing a quality slider around.

- Under 500KB: safe for almost every portal, text stays crisp
- Under 200KB: reduce scan resolution to 150 DPI, keep text selectable
- Under 100KB: expect visible softening on photos, use only for text-heavy forms

## Keeping text selectable and searchable

If your PDF already has a text layer, image optimisation leaves it alone and the document stays searchable. If you started from photos, run OCR first so the document has text at all, then compress. Compressing an image-only PDF cannot create a text layer.

Check the result: open the compressed file, zoom to 100% and confirm that small print such as an account number or a date is still readable. If it is not, go back one quality step rather than submitting a document that an officer cannot verify.

## FAQs (FAQPage schema ready)

### Will compression remove pages or fields?

No. Compression changes the quality of embedded images. Page count, text, form fields and bookmarks stay intact unless you use a separate page tool.

### Can I compress a password-protected PDF?

Remove the password first, compress, then protect it again. Encrypted files cannot be optimised while locked.

### Is my PDF uploaded anywhere?

No. Processing happens in your browser, so the document never leaves your device. This matters for bank statements and ID documents.

### Why did my PDF barely shrink?

If the file contains mostly text and vector graphics, it is already efficient. Compression targets images, so a 300KB typed PDF has little to save. Check the number of scanned pages.
