## The test we ran

Forty photographs from three phones, covering daylight portraits, indoor shots, screenshots and photographed documents. Each was exported at quality 95, 90, 80, 70 and 60, keeping the pixel dimensions unchanged. We then compared file size and looked for visible damage at 100% zoom on a colour-calibrated monitor.

## What actually happened

Quality 90 cut the average file size by 62% with no visible difference on any photo in the set. Quality 80 cut 78%, and the only place we could spot a change was fine foliage and fabric texture when zoomed in. Quality 70 reached 85% savings and started showing flat patches in dark areas. Quality 60 produced halos around sharp edges and clearly soft text in the document photos.

## The settings to use

For websites and WhatsApp, 80% is the sweet spot. For email attachments and quick previews, 70% is fine. For exam-form style uploads where a hard byte limit exists, drop quality only after reducing dimensions, and never go below 70% on a document that contains small text. Keep the original file untouched.

## Three things that ruin quality faster than compression

Exporting the same JPEG repeatedly, resizing a small image upward, and screenshots saved as JPEG instead of PNG. Fix those three habits and compression becomes almost invisible. A screenshot of text should stay PNG; a photograph should never be PNG.

## A repeatable workflow

Copy the file, reduce the longest edge to the size you actually need, compress at 80%, then check the byte size and one detail at 100%. If a portal rejects it, change dimensions before quality. This order keeps the result sharp and predictable.

## FAQs

**Does compression permanently destroy quality?**

It permanently changes the copy you save. The original is untouched, so always keep it and compress a duplicate.

**Is WebP always better than JPG?**

For web delivery it is usually 25–35% smaller at the same visual quality. For a portal that accepts only JPG, converting to WebP will get rejected, so match the requirement.

**Why did my image get bigger after compressing?**

That happens when you convert a well-compressed JPEG to PNG or save with a higher quality than the source. Check the output format before blaming the compressor.
