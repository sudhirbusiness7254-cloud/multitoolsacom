## What HEIC is, in one paragraph

HEIC is an image container built on HEVC, the same codec family used for 4K video. Apple made it the default because it stores the same visual quality in roughly half the bytes of JPEG. The catch is that older Windows versions, many web forms and plenty of print shops still cannot decode it.

## Why the file sometimes looks fine and sometimes does not

iPhone photos store rotation in metadata rather than rotating pixels. A converter that ignores that tag produces sideways images. This is the single most common complaint after conversion, and it is a converter bug rather than a user mistake.

## What you lose when you convert

Converting to JPG flattens the file. Live Photo motion, depth information used for portrait mode edits, and some EXIF fields do not survive browser-side conversion. If you need those, use the iPhone's own export or Settings → Camera → Formats → Most Compatible to shoot JPEG from now on.

## Batch converting a folder from a trip

Select everything, convert once, and keep the originals in a separate folder. A 200-photo set from a recent phone is around 400MB in HEIC and roughly double that in JPG, so convert only what you are actually sharing or uploading.

## Print shops and portals

Ask before sending HEIC. Most Indian print shops accept JPG only, and exam or visa portals almost always specify JPG under a size limit. Convert to JPG, then resize and compress to the stated numbers.

## FAQs

**Is HEIC better quality than JPG?**

At the same file size, yes, usually noticeably. At equal visual quality the HEIC file is smaller. The problem is compatibility, not quality.

**Can I convert HEIC on Windows without installing anything?**

Yes. A browser-based converter works on Windows, Mac, Android and iOS without installing a codec pack or an app.

**Does converting HEIC to JPG remove location data?**

It depends on the converter. Browser canvas conversion usually drops metadata, which is safer for sharing but loses useful camera information.
